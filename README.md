# Floating Quiz Timer

一个适合全屏刷题场景的 macOS 悬浮倒计时工具。窗口可以覆盖在 WPS、预览等全屏应用上方，帮助使用者控制每道题的作答时间，并记录正误题号。

<p align="center">
  <img src="bear/Resources/bear-start.png" width="150" alt="自嘲熊：开始答题" />
</p>

项目包含两个版本：

- **简洁版**：中性、严肃的紧凑界面，突出中央倒计时。
- **自嘲熊版**：根据倒计时进度切换熊图和提示语，适合希望练题过程轻松一点的用户。

## 功能

- 始终置顶，可在全屏应用上方使用
- 30、45、60、75、90、120 秒预设时长
- 支持输入自定义秒数
- 开始、暂停、继续和重置倒计时
- 标记每道题为正确、错误或跳过
- 查看正确、错误和跳过的具体题号
- 最小化到程序坞或直接退出
- 两个版本均提供独立应用图标

## 运行环境

- macOS 13 或更高版本
- Apple Silicon Mac
- Xcode Command Line Tools

## 构建

在项目根目录运行：

```bash
./scripts/build.sh
```

构建完成后，两个应用会出现在 `dist/`：

- `答题悬浮计时器.app`
- `自嘲熊答题计时器.app`

本地构建使用临时签名。首次打开时，如果 macOS 拦截应用，请在“系统设置 → 隐私与安全性”中确认是否允许打开。不要绕过来源不明应用的安全警告。
