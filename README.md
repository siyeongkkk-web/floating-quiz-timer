# 限时答题

这是一个为线上限时测评练习设计的 macOS 悬浮计时器。求职笔试和在线测评里，倒计时会直接影响答题节奏；我希望在平时用 PDF 或 WPS 刷题时，也能尽量还原这种按题限时的环境。

它可以浮在 WPS、预览等全屏窗口上方。做完一题后，还能顺手记下对、错或跳过，练完再回头看哪些题需要复盘。

## 它能做什么

- 常用的 30、45、60、75、90、120 秒一键切换，也可以自己输入秒数
- 开始、暂停、继续、重置，不用离开正在看的题目
- 给当前题标记“对 / 错 / 跳过”，并查看对应的题号
- 浮窗可以最小化或关闭；在全屏应用里也能使用
- 点击标题栏的图片按钮，可以为“从容、过半、冲刺”三个阶段分别选择图片和文案
- 倒计时进入不同阶段时，形象、提示语和状态颜色会一起切换；下次打开仍会保留

## 自定义自己的计时形象

1. 点击浮窗标题栏中的“图片＋”按钮，打开“三阶段形象”设置。
2. 分别为从容阶段、过半阶段和最后 10 秒的冲刺阶段选择一张图片。
3. 为每个阶段填写自己的提示语，点击“保存并使用”。
4. 计时器会随着剩余时间自动切换对应的图片和文案。想修改时再次打开设置；想回到简洁版，可以点击形象提示旁的“×”，或在菜单栏计时器图标中选择“恢复简洁模式”。

三张图片和文案只会复制到当前 Mac 的应用数据目录，不会上传网络，也不会写入 GitHub 仓库。请使用自己的照片、原创角色或已获得使用授权的图片。

## 怎么运行

目前是一个为 Apple Silicon Mac 打包的本地小工具，需要 macOS 13 及以上，以及 Xcode Command Line Tools。

在项目根目录运行：

```bash
./scripts/build.sh
```

完成后可以在 `dist/限时答题.app` 找到应用。

这是临时签名的本地构建。如果第一次打开时被 macOS 拦住，请到“系统设置 → 隐私与安全性”确认是否允许打开；只在你确认来源可信时这样做。
